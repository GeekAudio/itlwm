# Test127：定位发送完成事件

本版仅补这个缺口的最小记录：复用现有接收和完成解码，在接收分派前、实际处理分支及首次拒绝处保存同一运行的候选，并保留收尾前原因。记录不改变真实分派、成功判定、等待预算、频道许可或 DMA 释放规则。

采集继续使用已有的频道 6 单包流程和原 Test124 对端程序。目标是区分“完成事件未到达”“分派未命中”和“字段匹配拒绝”；回包、ROC END 或 BA 都不能替代精确完成。

连续收发和安全释放确认后，转入 iPhone 与 Mac 的系统原生隔空投送文件验收。联网冒烟和睡眠继续跳过。
