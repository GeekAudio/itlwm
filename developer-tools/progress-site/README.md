# 里程碑网页源码

`dist/` 是公开页面的完整静态文件，可直接通过 HTTP 浏览。包含 8×5 验收表、历史/本轮视图和开发总时间线。

`tools/` 保存原工作区的生成与发布脚本，路径布局依赖原来的运行工作区及不公开的验收源数据；这份快照不包含运行凭据和私有记录。`refresh_data.py` 先投影公开字段，发布脚本再做白名单检查和公开读取哈希核验。

`SOURCE-MANIFEST.json` 记录原相对路径与源码哈希。历史曾验收不等于当前版本复验，也不是项目完成率。

每次打开、浏览器后退返回或重新切回页面，都会用 `no-store` 和独立请求地址检查 `site-version.json`。发现新版后自动更新，保留当前章节；无需手动修改网址里的版本号。

`templates/index.html` 和公开数据由 `render_site.py` 生成同一份完整页面，数据、样式和脚本内嵌，避免缓存混用。发布前核对全部文件哈希，发布后读取线上文件确认一致。

GitHub Pages 的服务器缓存头由平台管理。离线、检查失败或发布尚未同步时，页面会明确提示并提供重试，不把旧页标成最新，也不会无限刷新。
