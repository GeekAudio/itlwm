# 即时热点与 AirDrop 被动日志

这是主机观测工具的源码快照。默认不采集；显式传入 `--capture` 后才运行，窗口为 15–120 秒。

工具保存共享、蓝牙和 Wi-Fi 的系统日志，以及起止接口状态和蓝牙快照，不会开关无线、连接网络或提权。原始文件只进入本项目 `research/` 下的新私有目录，不上传。原始日志和蓝牙快照可能含设备标识，分享前需要脱敏。

即时热点与两向 AirDrop 分窗记录。即时热点要区分蓝牙协商、手机自动激活、Wi-Fi 关联、地址分配和实际联网；成功、失败及恢复分别保留。AirDrop 以实际收件为准，文件可核验时再记录大小和 SHA。

`actions.jsonl` 用于另记人工动作与结果。Python 3.9 的单调时钟只在该进程内比较；跨进程或内核时间不能直接相减。窗口结束不等于功能成功，日志权限不足、脱敏和提前退出均可能留下证据缺口。

6 项 mock 检查通过；没有在本次启动执行真实采集。工具不包含驱动、EFI 或实测日志。
