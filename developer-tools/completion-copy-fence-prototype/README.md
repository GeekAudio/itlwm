# Completion 观察原型

用于离线验证“复制 8 字节”和“撤销视图后释放”之间的并发顺序，尚未接入驱动。原型先登记分配代号，再发布视图；拒绝迟到发布，禁止复制或移动 registry。

在本目录运行 `./run.sh`。包含 10 组交错与边界测试、4 项不可复制/移动编译期断言，以及核心无额外运行时符号检查。

这些测试使用普通内存和线程模型。内核锁、全部释放路径接线、模块卸载及真实 DMA 读取仍待验证；不会改变 RX 校验、队列索引或缓冲区选择。调用方必须在任何释放前登记同一代号，完成撤销后才释放；registry 和锁必须存活到全部 reader 与 handle 结束。禁止复制/移动并不自动保证单例，也不允许拿旧 handle 操作重建后的实例。
